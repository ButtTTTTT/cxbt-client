# 打包工具

用于将资源重新打包为 PDE 格式的工具集合。

## 工具列表

| 工具 | 类型 | 功能 |
|------|------|------|
| PDEPack.exe | GUI | 将资源目录打包为 `.pde` 文件 |
| ReCache.exe | GUI | 将普通文件打包为 `.cache` 文件 |

## PDEPack

将资源目录打包为新的 `.pde` 文件。

### 使用方法

1. 启动程序
2. 拖入或选择资源目录
3. 程序自动将目录中所有文件打包为 `.pde` 文件

### 应用场景

- 创建自定义资源包
- 替换游戏资源

## ReCache

将普通文件打包为 `.cache` 文件。

### 使用方法

1. 启动程序
2. 选择资源根目录（用于计算 CRC32）
3. 选择参考文件（获取前 8 字节魔数）
4. 选择要打包的文件

### 注意事项

- 打包后会替换原始参考文件，请提前备份
- 必须选择正确的资源根目录才能计算正确的 CRC32 值
- `.luac`文件后缀需要重命名为 `.lua` 后缀
