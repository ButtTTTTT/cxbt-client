# HTML 工具集

一组基于浏览器的轻量级工具，用于分析和处理二进制数据、计算偏移、转换浮点数等。

所有工具均为单页 HTML 文件，双击打开即可使用，无需后端环境。

## 工具列表

| 工具 | 功能 |
|------|------|
| `IEEE754.html` | IEEE754 浮点数计算器 |
| `OffsetCalc.html` | PDE 偏移值计算器 |
| `HEXVIEW.html` | 十六进制查看器 |
| `HalfFloatToUV.html` | 半精度浮点数转 UV |
| `FastXor.html` | XOR 快速验证 |
| `XorShiftOffset.html` | XOR 偏移扰动计算 |
| `DumpMeshBoneName.html` | MESH 骨骼名称提取 |
| `DumpAnimBoneName.html` | ANIM 骨骼名称提取 |
| `DumpSkelBoneName.html` | SKEL 骨骼名称提取 |

## 工具说明

### IEEE754 浮点数计算器

- 支持单精度（float32）和半精度（float16）
- 浮点数与十六进制相互转换
- 大小端模式切换
- 批量转换

**适用场景**：逆向分析、二进制协议调试、浮点压缩格式验证

### PDE 偏移值计算器

- 根据文件大小、块大小计算偏移
- 自定义块大小（0x1000、0x4000 等）
- 计算块索引/页号
- 历史记录

**适用场景**：文件格式逆向、VFS 结构分析

### 十六进制查看器

- 十六进制和文本对照显示
- 多种编码支持
- 适合复制到博客/文档展示

**适用场景**：展示十六进制示例、检查导出数据

### 半精度浮点数转 UV

- 半精度浮点（float16）转 UV 坐标
- 批量转换
- 历史记录

**适用场景**：模型/贴图 UV 修正与验证

### XOR 快速验证

- XOR 加密/解密运算
- 支持文本/十六进制输入输出
- 实时显示结果

**适用场景**：验证 XOR 协议、文件头掩码

### XOR 偏移扰动计算

- 分析偏移经 XOR 或位移后的映射关系
- 反向尝试恢复原始偏移

**适用场景**：带 XOR/位移的文件偏移编码逆向

### 骨骼名称提取工具

三个工具用于提取和整理骨骼名称：

- `DumpMeshBoneName.html` - 网格骨骼
- `DumpAnimBoneName.html` - 动画骨骼
- `DumpSkelBoneName.html` - 骨架骨骼

**适用场景**：对比不同资源的骨骼列表、检查命名一致性

## 使用方式

1. 双击 `.html` 文件，使用浏览器打开（推荐 Edge/Chrome）
2. 按页面说明输入数据
3. 手动复制结果保存

## 注意事项

- 所有工具在本地浏览器运行，不上传数据
- 部分页面依赖 `bulma.min.css` 样式
- 刷新页面会清空结果，请提前保存
