##### 第一个物体头部
    🌴 14000000 241E0000 483C0000 00000000 02000000 02000000 01A03E0C 00
    🥥 占用 0x1D 字节
        这个很重要！
    
    🌴 14000000 → 0x14 → 20
    🥥 表示当前.mesh文件内有多少个物体
        也就是说一个地图mesh文件中有多个物体
        经过观察发现需要-1才是真正有多少物体
            只有第一个物体的此描述才是共多少物体
            剩下的物体中描述的是自己有多少物体
    
    🌴 241E0000 → 0x1E24 → 7716
    🥥 表示此物体中有多少组面(faces)数据
        1组面数据需要3个参数,每个参数为4字节,
            所以一组需要 3*4=12 → 0xc字节
        因此可以计算出面数据内容有多大
            0x1E24 * 0xc = 0x169B0 字节
            因此当前物体的面数据大小为 0x169B0 字节

    🌴 483C0000 → 0x3C48 → 15432
    🥥 表示此物体中有多少组变换矩阵

    🌴 00000000 02000000 02000000 01
    🥥 未知

    🌴 01
    🥥 表示一个间隔，一般后面的4个字节就是变换矩阵数据大小
        但！这个01的位置上有时候不会写 01 !!!

    🌴 A03E0C00 → 0xC3EA0 → 802464
    🥥 表示此物体的变换矩阵数据大小
        如何计算其中一组变换矩阵的数据大小？
