# ReCache

Cache 文件打包工具，将普通文件打包为 `.cache` 格式。

## 功能特性

- 图形化界面，操作简单
- 将普通文件打包为 `.cache` 文件
- 自动计算 CRC32 校验值
- 支持从原始 `.cache` 文件提取头部信息
- 支持压缩（6D/6F 标志）
- 拖放操作支持

## 使用方法

1. 启动程序
2. 设置资源根目录（用于计算 CRC32）
3. 选择原始 `.cache` 文件作为参考（获取前 8 字节魔数）
4. 选择要打包的文件
5. 点击打包

## 输入与输出

| 输入 | 输出 |
|------|------|
| 普通文件 + 参考 `.cache` | 新的 `.cache` 文件 |

## 注意事项

- **必须选择正确的资源根目录**，否则 CRC32 计算不正确
- 打包后会替换原始参考文件，请提前备份
- CRC32 值与文件路径相关，移动文件会导致校验失败

## 编译要求

- .NET 8.0 SDK
- Visual Studio 2022
