# PDEPack

PDE 文件打包工具，将资源目录打包为 `.pde` 文件。

## 功能特性

- 图形化界面，操作简单
- 将资源目录打包为 `.pde` 文件
- 自动构建 VFS 表结构
- 支持 XOR 加密
- 拖放操作支持

## 使用方法

1. 启动程序
2. 拖入或选择要打包的资源目录
3. 程序自动在目录同级生成 `<目录名>.pde` 文件

## 输入与输出

| 输入 | 输出 |
|------|------|
| 资源目录 | `<目录名>.pde` |

## PDE 文件结构

打包后的 PDE 文件结构：

```
PDE 文件
├── XOR 加密层
├── VFS 表
│   ├── VFS 块 (4KB)
│   ├── 数据块 (4MB)
│   └── ...
└── 文件/目录条目 (每条 128 字节)
```

## 编译要求

- .NET 8.0 SDK
- Visual Studio 2022

## 注意事项

- 打包会覆盖同名 `.pde` 文件
- 保持原始目录结构
