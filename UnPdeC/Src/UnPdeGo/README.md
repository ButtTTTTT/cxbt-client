# UnPdeGo - 即将被淘汰

UnPdeC 的 Go 语言版本，用于解包 PDE 资源文件。

## 简介

本项目使用 AI 将 UnPdeC 的 C++ 代码转换为 Go 语言实现，功能与原版基本一致。

Go 语言语法简洁，性能优秀，跨平台编译方便。

## 编译要求

- Go 1.25.2+

## 编译方法

```bash
# 使用构建脚本
build.bat

# 或手动编译
go build -o UnPdeGo.exe
```

## 使用方法

与 UnPdeC 类似：

```bash
UnPdeGo.exe
```

程序会自动扫描当前目录的 `.xor` 文件并解包。

## 功能特性

- 解析 `.xor` 文件
- 递归导出目录和文件
- 对 `.cache` 文件执行二次解压
- 支持多种解压模式

## 与 C++ 版本的差异

| 项目 | C++ 版本 | Go 版本 |
|------|----------|---------|
| 性能 | 更快 | 略慢 |
| 内存 | 手动管理 | GC 自动管理 |
| 跨平台 | 需要重新编译 | 交叉编译简单 |
| 依赖 | VC++ 运行时 | 无依赖 |
