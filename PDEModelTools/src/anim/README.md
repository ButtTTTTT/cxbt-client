# .anim文件解析

## 第一人称 leader ak47 shoot.anim 为例
"animation\character\firstperson\leader\ak47\shoot.anim"

#### 魔数,数量,第一组动画头
```
OFFSET    00       04       08       0C        ASCII
00000000  00050000 33000000 04000000 726F6F74  ....3.......root 
00000010  3E000000 B2010000                    >.......         
```

##### 魔数/类型
```
00050000 → 0x50000 → .anim 文件的标志
```

#### 包含动画数量
```
33000000 → 0x33 → 包含51个动画
```

##### 第一组动画头
```
04000000 726F6F74 3E000000 B2010000
	04000000 → 0x4 → 骨骼名称长度
	726F6F74 → root → 骨骼名称
	3E000000 → 0x3E → 总帧数
		- 每帧数据是 0x1C = 28 字节
	B2010000 → 0x1B2 → 数据元素数量
		- floatCount / wordCount 用于校验/定位每轨道数据长度
		- 每帧数据是 0x1C = 28 字节
		- 28 / 4 = 7 个 uint32/float32
		- 对应内容刚好是 Position(3f) + Rotation(4f) → 7 个 float
```

#### 每组动画数数据占用字节
```
每组动画数数据占用字节 = 总帧数 * 一帧占用字节
0x6C8 = 0x3E * 0x1C
```
